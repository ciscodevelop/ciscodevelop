# Francesco Papa

**Founder di [FlowAxion](https://flowaxion.com)** — product architect focalizzato su piattaforme SaaS multi-tenant, automazione workflow, sistemi AI-assisted e prodotti digitali scalabili.

Costruisco software che trasforma la realtà operativa di un'azienda in memoria strutturata, workflow e azioni concrete.

---

## Cosa costruisco

- **Piattaforme web multi-tenant** con dashboard, moduli operativi e control plane.
- **Workflow automation** ed eventi, con attenzione a idempotenza, audit e affidabilità.
- **Frontend moderni** con React, Next.js, TypeScript, Tailwind e design system.
- **Prodotti AI-assisted** con guardrail, validazione runtime (Zod) e integrazione reale nei flussi applicativi.
